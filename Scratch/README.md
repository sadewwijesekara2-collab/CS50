This folder contains my projects developed using **Scratch** as part of my CS50 learning journey.

## 🚀 Projects

### 1. Virus Attack
A simple arcade-style game where the player must protect a laptop from incoming computer viruses.

**Features:**
- Click on viruses to eliminate them.
- Earn points by defeating viruses.
- Manage lives and avoid letting viruses reach the laptop.
- Game-over and victory conditions.

**Technologies:** Scratch

## 🛠️ What I Learned

- Using sprites and costumes.
- Working with variables and operators.
- Using loops and conditional statements.
- Handling user input and events.
- Creating clones and controlling sprite movement.
- Designing game logic and scoring systems.
